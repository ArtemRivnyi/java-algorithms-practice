# Contributing to Java Algorithms Practice

Thank you for contributing!

## 🚀 Guidelines

1. Build and test with Maven:
   ```bash
   mvn clean test
   ```
2. Code Style:
   * Follow standard Java naming conventions and clean architecture.
   * Write JUnit 5 test cases covering edge cases (empty inputs, nulls, boundary values).
   * Include Big-O time and space complexity notes in Javadoc.
